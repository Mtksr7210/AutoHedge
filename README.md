<h2>🛠️ Installation Troubleshooting (Simple Fixes)</h2>

<h3>❌ "Windows protected your PC" message</h3>
<p>This happens because AutoHedge is a new application withouta well-known digital signature yet. Click "More info" then "Run anyway". Safe to proceed.</p>

<h3>❌ App won't open after double-click</h3>
<p>Check if Windows Defenderis blocking it. Go to Windows Security > Virus & threat protection > Exclusions, add the AutoHedge folder. Then try again.</p>

<h3>❌ Can't connect to broker/exchange</h3>
<p>Make sure your API keys have "trading-permission" enabled (not just read-only). Also verify your computer's date and time are correct - blockchain connections fail if time is off by more than 60 seconds.</p>

<h3>❌ Slow performance</h3>
<p>Close other high-memory applications like Chrome tabs during active trading hours. You can also lower the "Data Refresh Rate" in Settings from 1-second to 10-second intervals.</p>
